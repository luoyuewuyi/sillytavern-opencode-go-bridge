# Changelog

## 0.3.0 — Transparent frontend preview

- Install directly using the SillyTavern extension URL; root manifest loads a two-file frontend runtime.
- Automatically add truthful User-Agent and per-chat x-opencode-session only to exact official Go Custom status/generate requests.
- Preserve authentication, settings, profiles, other providers, payload fields and original responses/streams.
- Remove Key panel, session vault, activation profiles, server plugin, protocol adapters and installation scripts from the main branch.
- Test stock ST 1.14.0/1.18.0 handlers in isolation; state OpenAI reverse_proxy/LWB independent-client limitations explicitly.
